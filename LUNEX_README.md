# Lunex Keyboard • Liquid Glass Edition

A personal Android keyboard based on [HeliBoard](https://github.com/HeliBorg/HeliBoard). The first milestone introduces rounded light and dark glass-inspired themes, a distinct Android package and preserves upstream typing/clipboard functionality.

**Important:** gesture typing needs an optional compatible proprietary library and is not provided by this repository. The glass design is a performant appearance preset, not genuine blurred pixels from the host app. See [development roadmap](docs/LUNEX_ROADMAP.md).
